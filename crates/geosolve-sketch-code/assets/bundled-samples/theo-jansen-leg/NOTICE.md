# Jansen linkage reference

This independently authored 2D constraint study uses the factual link ratios in
[Jansen’s linkage, revision 1370652486](https://en.wikipedia.org/w/index.php?title=Jansen%27s_linkage&oldid=1370652486).
The reference article is available under CC-BY-SA-4.0. No article text, illustration,
CAD model or software was copied. GeoSolve source remains GPL-3.0-or-later.

The sample interprets the published dimensionless ratios as millimetres and
models pin-jointed motion only; it does not model collision, loads or manufacturing.
