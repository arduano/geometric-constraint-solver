# Bundled renderer font

`ShareTechMono-Regular.ttf.base64` is the base64 encoding of Share Tech Mono Regular from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/sharetechmono), pinned for
hermetic native SVG rasterization. The decoded font SHA-256 is
`9ceab1f87414829af259c0f537573ae03ef7dd3147c0b27a36a1a0beb6732677`.
