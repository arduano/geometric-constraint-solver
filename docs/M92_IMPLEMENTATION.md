# M92 implementation: registry-first parallel sample rebuild

## Integration order

1. Land documentation and the canonical manifest/schema validator.
2. Migrate headless and frontend consumers with a clean terminology break.
3. Build sample waves in isolated worktrees; only integration owns registry plumbing and shared
   generators.
4. Compile/authenticate envelopes, add witnesses and provenance, then integrate each wave only when
   its focused validation passes.
5. Expand common native/managed oracle coverage using the defect-hardening ownership rules.
6. Run collateral and clean release qualification, freeze exact bytes and publish one M92 UAT.

## Parallel ownership

- mechanism wave: entries 1–5 and deterministic drag witnesses;
- fabrication wave A: entries 6–11;
- fabrication wave B: entries 12–16 plus third-party notices;
- atlas/scale wave: entries 17–20 and bounded dense-scene checks;
- integrator: schema, generator, public API, headless/report v2, frontend migration, oracle and docs.

Waves edit only their sample directories and focused tests. They do not independently edit shared
catalog arrays, package exports or milestone ledgers. Integration rebases/cherry-picks reviewed
commits in inventory order so generated bytes remain deterministic.

## Asset and public API contract

Each `assets/bundled-samples/<key>/` directory owns `manifest.json`, `sketch.ts`,
`sketch.compiled.json`, `witnesses.json`, and optional required `NOTICE.md`. Public Rust exposes
`SampleCategory`, `SampleExpected`, `SampleProvenanceRelationship`, `SampleProvenance`,
`BundledSampleSpec`, `bundled_sample_catalog()` and `bundled_sample(key)`.

The obsolete `SampleId`, `CodeProjectDemoId`, `CodeProjectDemo`, `BundledCodeProject`,
`bundled_code_project_demos` and `bundled_code_projects` surfaces are removed without aliases.
Headless similarly removes all demo spellings and report v1.

## Qualification

Focused registry/sample/witness tests run throughout. Final nomination requires:

```bash
cargo fmt --all -- --check
cargo clippy --locked --workspace --all-targets --all-features -- -D warnings
cargo test --locked --workspace --all-features
./scripts/golden-authoring-scene-oracle.sh --survey
./scripts/golden-authoring-scene-oracle.sh --check
./scripts/golden-authoring-scene-oracle.sh --require-clean
NO_COLOR=true nix-shell shell.nix --run './scripts/release-gate.sh'
```

Exact results and any reproduced finding IDs are appended before nomination.
