# M96-F006: full-rank large components stalled during seed preferences

The 12 mm manifold amendment added a separate stair passage. Changing its
reservoir-width dimension from 60 to 62 mm then rejected native publication
before channel boundary validation. Base source was `a918716` with active M96
working changes. The unchanged representative edit was independently reproduced
by the M87 bundled-sample edit/history test. This is a core priority-solver DEFECT.

The hard solve converged in eight iterations: the main component had 161 active
coordinates, 174 hard rows, rank 161 and zero numerical/bidirectional DOF. Its
maximum normalized hard residual was 7.6344683e-12. Its smallest retained singular
value was 0.00445561, well above the 1.89296e-9 rank threshold. The subsequent
Preference pass nevertheless stalled at iteration zero with unchanged cost 124.

At 128 coordinates the priority owner switches to an implicit hard projector.
That path represents the full coordinate dimension, even when actual tangent
freedom is zero. Subtracting a full-rank SVD row-space projection leaves rounding
noise. CGLS then tries to reduce that noise by a relative 1e-10; the later large
curvature guard would also withhold acceptance despite the empty hard tangent.

Detailed solver evidence is in `target/m96/thick-edit-attempt-diagnostic.log`.
Temporary diagnostic prints and error-format substitutions were removed.

The core regression
`m96_f006_full_rank_preferences_converge_across_projected_backend_boundary`
uses a cyclic affine matrix `2 I + 0.5 P`, with singular values in [1.5, 2.5],
and conflicting preferences at 127, 128 and 161 coordinates. Before the repair,
127 passed while 128 and 161 stalled. Independent hard residuals, unique x=2
solution, full rank, zero DOF and the nonzero preference cost are all checked.
The corrected regression passes all three sizes in 0.11 seconds.

`solver/priority.rs` now checks the numerical rank of large hard components
before assigning an implicit tangent map. Full column rank yields an explicit
zero-dimensional map without allocating a nullspace basis. The existing empty
search-space branch then reports convergence. Components with real tangent
freedom keep the existing operator/curvature path. Rank tolerance, residual
validation, preference cost and hard-vs-soft semantics are unchanged; no residual
equation or Jacobian changed.
