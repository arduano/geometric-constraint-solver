broad API coverage and honest scale while keeping source, UX, native execution and AI authoring in
one inspectable model.

## Quality boundary

Every entry is complete for first UAT: readable intentional source; one meaningful flat group for
every declaration; finite independently validated accepted geometry; normalized Hard residual
`<= 1e-9`; truthful DOF; minimal anchoring; explicit branches; inverse source/IR/project authority;
representative edit/Undo/Redo/reload; native/headless/release-WASM parity; and mechanism drag
witnesses. External references have immutable provenance and notices. There are no placeholder
entries or fake 3D views.

The registry is the only catalog authority. Frontend JSON is generated, not maintained. Headless
terminology clean-breaks to sample/report-v2 naming. Existing primitive and solver semantics are
used as-is; new geometry, residuals, solids, CAM, collision, LOD and optimization are out of scope.

## Release boundary

All mechanical gates and one immutable Tailscale UAT must pass before human review. GitHub Pages is
not updated until the supervising user accepts the composite UAT.
